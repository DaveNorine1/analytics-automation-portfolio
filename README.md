# Dave Norine: AI Automation & Marketing Analytics Projects

Small, practical builds that save teams time or answer the budget question in the room. Each folder has its own README with setup steps and results.

| Project | What it does | Built with |
|---|---|---|
| [Inquiry auto-drafter](gmail-ai-inquiry-autodrafter) | Reads web-form inquiries in Gmail, picks the right attachments, and drafts a reply in the owner's voice. Nothing sends without a human. | Google Apps Script, Gemini API, Gmail, Drive |
| [Tracking & consent QA suite](tracking-consent-qa-suite) | Drives a real browser through a site and checks that GA4 and ad pixels respect cookie consent, conversion events fire, and UTMs survive redirects. | Python, Playwright, GA4 |
| [Marketing ROI scenario planner](marketing-roi-scenario-planner) | Answers "what would it take to hit 3:1?" live, with a matching formula-driven Excel model. | JavaScript, SVG, Excel |
| [Media mix model and customer value](marketing-mmm-clv-case-study) | MMM graded against known truth, a same-budget reallocation, RFM segments, CLV by channel, and a repeat-purchase model. | Python, SciPy, scikit-learn |
| [Consumer sentiment forecasting](consumer-sentiment-forecasting) | UMich capstone findings plus a leakage audit that rebuilt the forecast against a naive baseline. | Python, statsmodels, scikit-learn |

More analytics and data science work, including media mix modeling, geo testing, retention modeling, and an LLM support agent, is in [DaveNorine1/Portfolio](https://github.com/DaveNorine1/Portfolio).

All data and businesses here are fictional or anonymized. Nothing comes from an employer.
